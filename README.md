# SwiftUI In Practice

Pure SwiftUI recreations of popular app interfaces — built to practice layout, navigation, and animation without the distraction of real data or networking.

This repo recreates the UI of:

- **Bumble** — swipeable card stack UI
- **Netflix** — home feed with horizontal content rows
- **Spotify** — now-playing and browse screens

## Focus

This project is UI-only. No backend, no persistence — every screen is built with static/mock data (placeholder products, not real films, songs, or people) so the focus stays entirely on:
- View composition and layout (`VStack`/`LazyVStack`, `HStack`/`LazyHStack`, `ScrollView`, `ZStack`, `LazyVGrid`/`LazyHGrid`)
- Custom navigation and tab structures
- Gestures (swipe, drag) and transitions
- Animations and view transitions
- Reusable, reusable-style SwiftUI components
